# MUGB

Public source and asset repository for the MUGB RimWorld mod.

The playable release is published separately on the Steam Workshop. This
repository contains the C# source, XML definitions, translations, textures,
sounds, and editable art source files used to maintain the mod.

## Building

The project targets .NET Framework 4.7.2. Set `RIMWORLD_PATH` to the local
RimWorld installation and `HARMONY_PATH` to `0Harmony.dll` before building.
