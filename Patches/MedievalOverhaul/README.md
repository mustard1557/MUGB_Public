# Medieval Overhaul compatibility notes

이 폴더는 Medieval Overhaul 선택 호환 패치를 넣기 위한 자리입니다.

현재 의도:
- MUGB 본체는 Medieval Overhaul을 선행으로 삼지 않습니다.
- 만년스프솥, 중세 연료/재료, 중세 테크레벨 무기 조정은 여기의 `MayRequire="DankPyon.Medieval.Overhaul"` 패치로만 추가합니다.
- 아직 실제 패치 XML을 넣지 않은 이유는 빈 `Patch` 파일이 림월드 로딩에서 불필요한 위험을 만들 수 있기 때문입니다.
